# Torn Veil current build - October 11, 2026

The primary path is **Play Torn Veil.cmd**, also available as **Play Torn Veil Web.cmd** or `npm run play`. It opens the persistent connected realms and the canonical Tower. `npm run play:build` compiles `dist-web` and writes `current-build.json` with the exact clean Git commit. The launcher displays that commit and refuses a stale build or a host from another checkout. `/realms/health` reports the running source root and compiled build identity.

The primary build requires the audited local Mixamo and unarmed motion dependencies and records their hashes. It stages existing matching files from the shared repository or `TV_REALMS_ASSETS`, and fails if they are unavailable or differ. These licensed raw motions remain gitignored; a fresh machine must supply its licensed copies or reproduce them as documented in `docs/COMBAT_ARENA.md`. Fallback body kits are generated by `npm run web:assets`. No raw licensed motions or private replacement assets are pushed.

## Known defects and limits

- This is a playable procedural foundation, not a finished megacity or visual equivalence to the referenced video. Far structures are streamed/rendered with bounded simulation; four nearby residents do not prove a population of millions.
- Garment intersections, open-hand combat silhouettes and cast-specific posture differences remain. Controlled neutral posture improves; full character art acceptance remains open. The private replacement character was visually rejected and is excluded.
- City exploration and Tower presentation share assets/identity but still have separate camera/input shells. Exploration is first person; the Tower shows the controlled body. City-wide combat and full inhabitability remain roadmap work.
- Source transformations through Silver are implemented as receipt-bearing rules. Their kill/form/material thresholds are authored provisional balancing, not a measured several-hour progression guarantee. The embodied Normal→Iron practice path remains separate.
- **New Gold source promotions are paused pending human policy acceptance.** The full ontology ladder and previously saved capacities remain retained. No floor counter, legacy XP or accelerated fixture establishes real human pacing.
- Late-floor journal saves avoid synchronous full serialization on ordinary flushes, but structural rollback captures, simulation/GC spikes and logical history growth remain scaling limits. Prior floor-95/summit results are copied-save tests, not a fresh timed human climb on this consolidation.

Use a clean **main checkout** and its launcher. A second checkout can use `Play Torn Veil.cmd -Port 7550`. The save is `.debug/realms/world.json.store/`; the original `.json` import is retained. Choose a separate `TV_REALMS_SAVE` for disposable QA. Do not overwrite a real save with an accelerated fixture.

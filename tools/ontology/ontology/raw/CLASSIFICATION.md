# Vocabulary classification

These labels are editorial hypotheses, not simulation facts. Entries can inhabit several dimensions. Vampire is normally a state on a biological species; boss is an encounter role; merchant is a profession; culture is orthogonal to species. Names such as Drow can include biology and culture: the simulation adapter must disambiguate.

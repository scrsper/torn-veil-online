# Art-reference guide

The supplied 18-image set has been visually inspected in full. [Evidence analysis](REFERENCE_ANALYSIS.md) supersedes the bootstrap's unset art direction. Omni, Kestrel and the Kestrel sheet are the primary Human guides; Orc references support a later shared-topology derivation. No mesh is approved by this intake.

Highest value next: registered male/female neutral A-pose front/side/back with height scale; neutral head front/profile/three-quarter; dorsal/palm/side hands; construction views of plain shirt/blouse, trousers, belt and calf boots; an equal-scale **Human / Elf / Orc / Dwarf lineup**. Elf and Dwarf visual evidence is currently absent. Actual game-camera parameters are now sourced from the Babylon client; a gameplay screenshot is still valuable for composition and lighting intent.

Keep the next work focused on Humans and shared humanoid derivatives. Plain civilian workwear precedes armor; neutral-light skin/linen/leather swatches will help separate material color from the warm sunlight in the illustrations.

Each reference should explain which properties are authoritative: head-to-height ratio, shoulder breadth, hands/feet, facial planes, stylization, texture detail, armor construction, culture, silhouette or color. Mark positive and negative examples explicitly. A polished illustration alone often leaves hidden-side topology, scale and animation needs ambiguous; annotate those gaps rather than guessing.

Use `references/` categories and metadata. The DRAFT `ArtDirectionProfile` and Human family record distinguish observed qualities from provisional numeric engineering targets. None of the numeric proportions or budgets is a measured fact from these perspective images. Neutral catalog lights remain inspection defaults. Quaternius proportions are no longer the Human visual target.

Approval applies to an entity + components + rig + material set + profile version + game-camera presentation. Attractive source artwork alone does not approve every derived species or outfit combination.

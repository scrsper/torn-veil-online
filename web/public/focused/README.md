# Torn Veil focused runtime handoff

Existing asset selection only, for a small town, nearby ruins, forest and Tower of Chrysanthus milestone. Start with runtime_manifest.json. Import GLBs at scale 1; their self-contained meshes/materials are already assembled. Do not instantiate metadata placements again.

## Selection rationale
- Home: corrected single-floor Bridgeport, tv_26_05_timber_house. Warm timber structure, readable living/kitchen/nook and two-bedroom layout; full strict static route and fixture-approach pass, without an approved access exception. The original source plan and uniform 1.44 horizontal adaptation remain disclosed.
- Town: a cobbled street, Brass Lantern Tavern and general store. The street has attachment bays; the corrected home requires a separately validated threshold connection rather than old V2 house placement. No rejected V2 house exports are included.
- Landscape: ruined cloister plus three authored forest route shapes (pine cross route, branching pine, turning broadleaf). Keep the paths and ground metadata, not just tree silhouettes.
- Tower: existing shell/stair entrance, three tower halls, three junctions, two additional elevation variants, crypt, vault, archive and boss chamber. These provide a coherent stone interior palette and routing variety. Twenty-five optional loose modules support later closures and dressing.

## Contract and limits
Every GLB and original metadata file is byte-for-byte copied; provenance and SHA-256 are recorded. Selected static audits are small JSON evidence, not a new test run. The house has a stricter corrected-house gate; V2 route passes do not claim the same source-plan review. Loose modules have authoring intent, not independent traversal certification.

The 100-floor requirement is a consuming-game goal. This ZIP supplies a reusable pool and connector contract, not a generator, generated floors, certified joins, custom tower exterior, gameplay or a runnable game. A seeded generator must check overlap, seam support, reachability, unused openings and controller clearance for each floor.

Spawn suggestions are foot positions in both conventions. They must be grounded and overlap/sweep-tested with the final controller. A passed source sample is not a runtime spawn guarantee. Preserve open doors; animation and closing/opening behavior need new validation.

Original source paths inside provenance identify where exact source evidence came from; missing Blend/source-report paths in original manifest records are not runtime dependencies. No Blend files, PDFs, bulk renders or source-generator files are bundled.
